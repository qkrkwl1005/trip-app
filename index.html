시도 순서: -
Google Cloud에서 Maps JavaScript API를 사용 설정하고 결제 계정 및 현재 사이트의 HTTP 리퍼러 제한을 확인하세요. 키가 없거나 인증에 실패하면 OpenStreetMap으로 전환하고 지도에 안내를 표시합니다.
iPhone 단축어 만드는 방법 (약 2분)
1. 단축어 앱 → +로 새 단축어
2. ⓘ(정보) → "시트에서 받기" 켜기 → 텍스트·URL 허용
3. 작업 추가: "텍스트" → 위에서 복사한 주소 붙여넣기
4. 그 줄 끝에서 변수 삽입 → "받은 입력"(시트 입력) 연결
5. 작업 추가: "URL 열기" → 입력을 앞의 텍스트 결과로 지정
6. 이름 "여행플래너 저장"으로 저장
지도를 불러오지 못했어요. API 키 또는 네트워크를 확인해 주세요.
