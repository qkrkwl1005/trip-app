OpenRouter 키는 무료 모델도 사용 가능 — 모델칸을 비우면 무료 라우터(openrouter/free)를 씁니다. Gemini는 무료 쿼터(분당 횟수 제한)라 순서는 Gemini → OpenRouter로 돌아요. Google My Maps → 지도 열기 → 공유 → 링크 복사 (mid= 포함된 주소)
iPhone 단축어 만드는 방법 (약 2분)
1. 단축어 앱 → +로 새 단축어
2. ⓘ(정보) → "시트에서 받기" 켜기 → 텍스트·URL 허용
3. 작업 추가: "텍스트" → 위에서 복사한 주소 붙여넣기
4. 그 줄 끝에서 변수 삽입 → "받은 입력"(시트 입력) 연결
5. 작업 추가: "URL 열기" → 입력을 앞의 텍스트 결과로 지정
6. 이름 "TripSync 저장"으로 저장

이후 인스타/유튜브에서 공유 → TripSync 저장 선택하면 앱이 열려 장소를 바로 찾아요.
Android: 단축어 불필요 — Chrome에서 앱 설치하면 공유시트에 TripSync가 바로 나와요.
